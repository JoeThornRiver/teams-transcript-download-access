# Security Policy

## Supported versions

Security updates apply to the latest published release.

## Report a vulnerability

Do not open a public GitHub issue for a suspected vulnerability.

Use the repository's **Security** tab and select **Report a vulnerability**. GitHub Private Vulnerability Reporting keeps the report and discussion private while the maintainers investigate.

Include the affected version, observed behavior, reproduction steps, and impact. Do not include real tenant credentials, access tokens, participant data, recording URLs, or other personal data.
